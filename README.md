# Daily Activity Planner Chatbot

GEMINI powered chatbot for planning daily activities built using Python, Streamlit and GEMINI API.
Chatbot able to understand user input, suggest activities based on user preferences, and help organize their schedule. 
It can also provide reminders for upcoming tasks and offer tips for time management.
It will send messages to users via email if they want to receive their daily tasks and reminders.

## Features

- Good user interface using Streamlit
- Store data in a database to keep track of user preferences and past interactions
- Implement natural language processing (NLP) capabilities to understand user input and provide relevant suggestions
- Allow users to input their daily tasks and activities, and the chatbot will help organize them
- Send daily task to mail, if user wants to receive it via email
- Provide reminders for upcoming tasks and deadlines

## Tech Stack

- Python
- FastAPI
- Gemini API
- LangChain
